## contribs.sh

**Every contribution, every forge, one heatmap.**

Your GitHub graph only shows one account on one platform. contribs.sh merges every account you've used
(github.com, GitHub Enterprise, Forgejo/Codeberg), counts commits from repos still on your disk, and
exports the result as a banner for X, LinkedIn and more.

```bash
npx contribs.sh init
npx contribs.sh banner
```
